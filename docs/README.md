# dot help

Start with [installation](install.md) and [getting started](getting-started.md).

- [Configuration](config.md): every dot.toml key, with examples.
- [Commands](commands.md): flags, output and exit codes.
- [Sync](sync.md): remotes, timers, conflicts and refusals.

The setup lives in `~/.dot`. Set `DOT_HOME` to use another folder.
The machine name is the short hostname. Set `DOT_MACHINE` to override it.
