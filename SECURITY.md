# Security

Report a vulnerability privately through GitHub's private vulnerability reporting on
[fschrhunt/dot](https://github.com/fschrhunt/dot/security/advisories/new). Please do not open a
public issue for it.

dot writes the files your setup lists, as you, to the places you list. That is its job, not a
vulnerability. Anyone who can push to your setup's git remote can change what dot writes on every
machine that syncs from it, so keep that remote private and its access tight.
